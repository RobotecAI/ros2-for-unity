# Third-party notices: ROS2 For Unity release packages

ROS2 For Unity is licensed under the Apache License 2.0 (`LICENSE.AL2`); its own notice is in `NOTICE`.
The release packages published on GitHub also contain software by other authors, listed here with their
licences. This file covers the packages of releases 1.3.0, 1.2.0 and 1.1.0 and the packages built by
`create_unity_package.sh` / `create_unity_package.ps1`.

## 1. What each release package contains

| Release | Package | Third-party content |
|---|---|---|
| 1.3.0 | `Ros2ForUnity_humble_standalone_ubuntu22.zip` | ros2cs, ROS 2 Humble runtime (§2.2), interface packages (§2.3), tf2 (§2.4), Fast DDS, Fast CDR, Cyclone DDS, iceoryx, libyaml |
| 1.3.0 | `Ros2ForUnity_humble_standalone_windows11.zip` | ros2cs, ROS 2 Humble runtime, interface packages, tf2, Fast DDS, Fast CDR, Cyclone DDS (with the security plugins and the IDL library), libyaml, spdlog, TinyXML-2, OpenSSL, Microsoft Visual C++ runtime |
| 1.3.0 | `Ros2ForUnity_galactic_standalone_ubuntu2004.zip` | ros2cs, ROS 2 Galactic runtime, interface packages, tf2, Fast DDS, Fast CDR, Cyclone DDS, iceoryx, libyaml, and `libdl-2.31.so` from the GNU C Library (§2.14) |
| 1.3.0 | `Ros2ForUnity_humble_overlay_ubuntu22.zip`, `Ros2ForUnity_humble_overlay_windows11.zip`, `Ros2ForUnity_galactic_overlay_ubuntu2004.zip` | ros2cs, interface packages, tf2 |
| 1.2.0 | all six packages (`foxy`, `galactic`, `humble`; Ubuntu and Windows) | ros2cs, interface packages, tf2; the Foxy packages also rcpputils. No 1.2.0 package bundles the ROS 2 runtime or a DDS implementation |
| 1.1.0 | `Ros2ForUnity_WindowsFoxy.unitypackage`, `Ros2ForUnity_WindowsGalactic.unitypackage` | ros2cs, ROS 2 Foxy / Galactic runtime, interface packages, tf2, Fast DDS, Fast CDR, Cyclone DDS, libyaml, spdlog, TinyXML-2, OpenSSL, Microsoft Visual C++ runtime |
| 1.1.0 | `Ros2ForUnity_UbuntuFoxy.unitypackage`, `Ros2ForUnity_UbuntuGalactic.unitypackage` | ros2cs, interface packages, tf2 |

Not included in any package, and provided by the operating system or a ROS 2 installation where they are
needed: the C and C++ runtime libraries, libacl, OpenSSL (Linux), TinyXML-2 (Linux), spdlog (Linux),
rclcpp, rclcpp_action, class_loader, console_bridge, libstatistics_collector and Orocos KDL. The packages
link to them dynamically.
